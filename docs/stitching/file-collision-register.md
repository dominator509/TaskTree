# file-collision-register.md - Phase 5A Collision Register

> Phase 5A stitching artifact. This register prevents silent overwrite drift.

## Collision Rule

Latest phase wins only when the later phase explicitly patched the file as an approved deliverable. Accidental collisions require manual review and must not be silently overwritten.

## Known Collision Classes

### `tools/find-spec-derivations.ps1`

- Generated in many phases.
- Selected source: latest Phase 5A version after this bundle is applied.
- Reason: marker registry evolves by phase.
- Phase 5B review: verify grand total and zero-marker phase handling.

### HANDOFF delta files

- Pattern: `docs/HANDOFF-v1.0.xx-delta.md`
- Rule: retain all deltas; do not overwrite/collapse in Phase 5A.
- Reason: preserves traceability.

### Production files patched across phases

Examples:

- `src/TaskTree.Modules.AutoUpdater/AutoUpdater.cs`
- `src/TaskTree.Modules.BugReporter/BugReporter.cs`

Rule: latest approved patch wins, but earlier generators must be recorded as superseded.

### Test files patched across phases

Examples:

- `tests/TaskTree.Modules.AutoUpdater.Tests/AutoUpdaterTests.cs`
- BugReporter tests and integration tests.

Rule: latest approved patch wins, with Phase 5B compile/test reconciliation.
