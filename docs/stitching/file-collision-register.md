# file-collision-register.md - Phase 5A Collision Register

> Phase 5A stitching artifact. This register prevents silent overwrite drift.

## Collision Rule

Latest phase wins only when the later phase explicitly patched the file as an approved deliverable. Accidental collisions require manual review and must not be silently overwritten.
